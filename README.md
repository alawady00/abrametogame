# عبرميتو: مدار الذاكرة

لعبة ذاكرة وانتباه وتفكير للعائلة والفصل: 3 مستويات، 4 جولات، 60 تحدّيًا، بنظامين: **فردي** و**جماعي** (الموبايل مع القائد واللاعبون بالورقة والقلم).

لعبة من ابتكار وإعداد الأستاذ عبد الرازق العواضي.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع **كل** محتويات هذا المجلد كما هي: `index.html` و`css` و`js` و`assets` و`custom.json` و`.nojekyll`.
3. من **Settings ← Pages** اختر: Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر رابط اللعبة: `https://اسم-حسابك.github.io/اسم-المستودع/`

> تحتاج اللعبة إنترنت لتحميل الخطوط (Cairo وLalezar) فقط؛ لو غابت تعمل بخط بديل.

## التعديل من داخل اللعبة (لوحة المعلّم)
من الشاشة الرئيسية اضغط **⚙ لوحة المعلّم** (أو افتح الرابط وأضف `#admin` في آخره):

- **تعديل الأسئلة:** نص السؤال، الزمن، نوع العرض (متتابع/حكاية/أزواج)، الخيارات والإجابات الصحيحة، مع زر **معاينة**.
- **الإعدادات:** أسماء المستويات وأعمارها، ثواني عرض المشهد، سرعة العروض، زمن بطاقات الألوان، عدد نجوم المراهنة، ونسب المكافأة والقطعة الناقصة.
- **القطعة الناقصة:** أضف بطاقات التحدّي أو عدّلها.
- **رمز حماية** اختياري للوحة.

التعديلات تُحفظ في متصفح الجهاز نفسه. ولنشرها لكل من يفتح اللعبة:
1. من اللوحة اختر **تصدير واستيراد ← تنزيل custom.json**.
2. استبدل ملف `custom.json` في المستودع بالملف الجديد.
3. يرى الجميع التعديلات عند فتح اللعبة (تعديلات المتصفح المحلية تتقدّم على الملف؛ استخدم «إعادة كل شيء للأصل» لتصفيتها).

## تعديل الصور
استبدل صور المشاهد في `assets` بنفس الأسماء: `scene1.jpg` (المستوى 1) و`scene2.jpg` و`scene3.jpg`.

> اللعبة للتسلية وتنشيط الانتباه والذاكرة، وليست اختبار ذكاء.
